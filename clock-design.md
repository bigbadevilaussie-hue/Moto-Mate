## Test sequence
1. Upload V1.21 in normal BENCH maintenance. GET clock before sync; unknown UTC must not produce a trusted event timestamp.
2. Run python3 tools/moto_clock.py 192.168.8.136 --sync. Verify host_synced and UTC offset; compare RTT/2, host clock accuracy and actual processing delay.
3. Arm bench_sleep=1, then reset. A non-sleep reset deliberately discards provenance; to measure holdover without rebooting after sync, a later same-boot sleep-entry integration is required. Do not claim this reset-start test proves trusted holdover. A saved timestamp is not a running clock. Inspect platform_utc_us on successive timer wakes and on button escape; compare with host UTC only as unverified platform measurement.
4. Test malformed/out-of-range input, backwards/forwards correction, power removal and OTA; all monotonic deadlines must remain unchanged. No FIELD operation.
