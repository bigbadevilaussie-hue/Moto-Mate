# V1.07 isolated BLE commissioning — B1

USB BENCH only; 90 s coordinator unchanged. V1.06 baseline checks retained. On successful initial Wi-Fi, clock and Wi-Fi OFF + 800 ms guard, advertise Moto-Mate-B1 for at most 40 s, two distinct completed GATT connections required. Local success means valid challenge write, notification submitted, valid clock write applied and disconnect on both connections, plus controller and Bluedroid shutdown verified. OSA separately checks actual notification and readback. Only after successful BLE shutdown and local sessions do existing Wi-Fi commissioning and 800 ms guard run again. No production BLE manager, file uploads, alerts, TFT hardware or deep sleep. Failure or missing client is failure, not fake PASS.

Service 0da70001-7d91-4a75-9a7c-56d1f29b0731; same suffix for chars 0002 identity READ ASCII MMB1/1.07/<8 hex boot id>, 0003 challenge WRITE/NOTIFY 8-byte nonce, 0004 clock WRITE uint32 LE UTC epoch then READ actual device epoch + applied epoch (two uint32 LE). All fit default 20-byte ATT payload. OSA subscribes before challenge and verifies exact nonce; checks applied epoch equals requested and current epoch agrees within 2 s. Same boot ID across reconnect. No production security claim; bench-only, no sensitive actions. Shutdown and Wi-Fi recovery measured on serial; host cannot prove radio off just from disconnect.
