# V1.10 OTA maintenance bench

Owner requests OTA before moving bare S3 to buck-powered breadboard. Dedicated always-awake Wi-Fi bench, no BLE, sensors, TFT or GPIO outputs. Existing proven BenchCommission Wi-Fi bring-up sequence retained; optional keep-connected branch skips clock and shutdown only on successful association. Failed association shuts down and retries after 30 s. HTTP port 80 /status and authenticated multipart POST /ota, application only, local randomly generated independent token in ignored Ota.local.h (0600). Plain HTTP on trusted isolated LAN only, not encrypted/signed firmware. Never expose port to Internet. No production OTA or sleep integration yet.

First USB compile/upload, check /status, then upload same V1.10 app over LAN using tools/ota_upload.py; verify changed boot ID, alternate OTA partition and expected version. Device validates declared size, ESP32-S3 header, exact written bytes and MD5 via Update, finalizes only after complete request; abort incomplete uploads. SDK synchronous WebServer/Update timeouts apply; power loss and bad-app rollback not validated; USB recovery retained. Subsequent builds must retain OTA and same local key or wireless path will be lost. Same-version first test proves transport/slot switch, not new code behavior. Use stable supply; disconnect USB before attaching buck 5V, verify buck unloaded and loaded, no simultaneous supplies unless board isolation proven. OTA bench remains awake intentionally; not safe as unattended field firmware. No OSA change required.
