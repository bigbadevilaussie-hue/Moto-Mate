# Moto-Mate MkII

The overengineered, colour-screen successor to Bike-Mate.

## Features
* ESP32-S3 Super Mini
* 1.8" ST7735 TFT Colour Display
* 1mA Deep Sleep Budget
* 12V Switched Line (IRF4905 High-Side)
* BLE Telemetry (Arduino Core 2.0.17 ONLY)
* OTA Updates (Wi-Fi Maintenance Mode)
